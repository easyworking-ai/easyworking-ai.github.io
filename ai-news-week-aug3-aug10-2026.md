## 1. Meta Launches Muse Code — Its First AI Coding Agent (Aug 5)

- **Date:** August 5, 2026
- **Sources:** 
  - CNBC: https://www.cnbc.com/2026/08/05/meta-debuts-muse-code-to-take-on-anthropic-and-openai-.html
  - TechCrunch: https://techcrunch.com/2026/08/05/meta-launches-muse-code-an-ai-agent-for-large-code-bases/
  - 9to5Mac: https://9to5mac.com/2026/08/05/meta-launches-muse-code-ai-coding-agent-for-macos-and-linux/
- **What happened:** Meta released its first AI coding agent called **Muse Code**, positioning it as a competitor to Anthropic's Claude Code and OpenAI's Codex. The tool lets developers install with a single command and use it for complete software engineering tasks — planning changes, writing code, and validating results. It works alongside Meta's latest AI model, **Muse Spark 1.2**.
- **Who announced it:** Meta, led by AI chief Alexandr Wang (head of Meta Superintelligence Labs). Wang joined Meta in June 2025 as part of CEO Mark Zuckerberg's effort to revamp the company's AI strategy.
- **Pricing:** Pay-as-you-go at $1.25/million input tokens and $4.25/million output tokens (matching Muse Spark 1.1 pricing). A contributor tier is "more than 10x cheaper" but requires opting in to data collection. Meta is also starting to accept zero-data-retention requests for enterprise users.
- **What changes for users:** Developers now have a major new AI coding agent option from Meta, available on macOS and Linux, priced to compete on cost rather than capabilities against Anthropic and OpenAI.

## 2. Cloudflare Launches Kitesurf — A Browser Built for AI Agents (Aug 7)

- **Date:** August 7, 2026
- **Source:** TechCrunch: https://techcrunch.com/2026/08/07/cloudflare-launches-kitesurf-a-browser-built-for-ai-agents/
- **What happened:** Cloudflare launched **Kitesurf**, a browser specifically designed for AI agents (not humans). It provides a headless browsing environment that AI agents can use to navigate websites, fill forms, and interact with web applications programmatically.
- **Who announced it:** Cloudflare
- **Author:** Sarah Perez (TechCrunch)
- **What changes for users:** This is infrastructure for developers building AI agent workflows. Instead of building custom web scraping tools, developers can use Kitesurf as a standardized browser layer for their AI agents to interact with the web.
