## AIの表が破綻する瞬間

四半期レポートに使う表が必要になりました。過去3つのレポートをAIに貼り付け、「直近3年間の四半期ごとの売上成長率の表を作って」と入力しました。数秒で完成した表が返ってきました。整列され、単位もそろっています。レポートの下書きにそのまま入れました。

役員会の翌日、戦略企画チームから連絡がありました。「2024年第3四半期の売上、私たちの資料と数字が違うのですが」。確認すると、AIが2つのレポートにまたがって出てきた数字を転記する際に一つを間違えて貼り付け、そもそも存在しなかった一つのセルを推定値で埋めていました。文章なら読んでいる途中で違和感に気づいたかもしれません。表は違います。数字がずらりと並んでいると、人は内容を読まずに通り過ぎてしまいます。表の見た目が完成しているほど、検証が省かれます。ここが問題です。

AIが作った表が崩れるポイントは大きく3つあります。

1. **出典のない数字。** 資料にないセルを空欄にせず、もっともらしい値で埋めます。学習データにあった似た数値を持ってきた可能性もあれば、単に推測した可能性もあります。
2. **計算ミス。** 成長率、合計、構成比などの派生数値で間違えます。AIは桁数の多い算術が苦手です。
3. **時点の混同。** 2023年の調査値を2025年の数値のように表へ入れます。表に年が書かれていても、その年が出典の年と一致しているかは別の問題です。

## 機能するプロンプト

表を作ってもらう時は、3つの条件を加えます。出典を示せないセルは埋められないようにし、計算は過程を見せ、資料が食い違う時は隠さないようにします。

```
以下の資料から比較表を作成してください。

ルール:
- 資料に記載されている数字だけを使ってください。資料にないセルは絶対に推測で埋めず、「資料なし」として残してください
- 各数字の横に出典を付けてください。出典は「資料名 + 該当する文」の形式にしてください
- 成長率や合計を計算した場合は、計算式を表の下に別途示してください
- 資料間で数字が異なる場合は、一方だけを選ばず両方を表示し、どちらがより新しい資料かを知らせてください

作成する表:
[ここに表の形式を直接記入します。例: 年（行）×製品群（列）、単位: 億ウォン]

資料:
"""
[レポート、議事録、Excelから貼り付け]
"""
```

このプロンプトが「表を作って」と違う点は3つあります。

第一に、**空欄を許容しています。** 「資料なし」のセルができたら、そのセルは人が埋めます。AIが推定で埋めるより、空いているほうがよいのです。空欄なら埋める必要があるという合図になりますが、もっともらしい数字が入っていると誰も確認しません。

第二に、**出典を文単位で付けさせています。** 「出典: 2024年事業報告書」程度では不十分です。どの文から出た数字なのかまで尋ねると、後で原文と照合できます。出典を示せない数字は、AIが作った数字と考えるべきです。

第三に、**資料間の不一致を隠させないようにしています。** 2つの資料が異なる数字を示すとき、AIは通常どちらか一つを選びます。どちらが新しいかを判断するのは人の仕事なので、判断材料を受け取れる構造にします。

## 検証チェックリスト

AIが返した表をレポートに入れる前に確認します。数字が多い場合はすべてを見るのが難しいため、間違えると困る数字から確認します。

- [ ] 出典が付いていない数字はないか。「資料なし」のセルをそのまま残していないか？
- [ ] 合計・成長率を電卓やスプレッドシートでもう一度計算したか？
- [ ] レポートの結論に直接影響する数字3つを、原出典の文書で直接確認したか？
- [ ] 各数字の基準時点（調査年、四半期）が表に書かれているか？
- [ ] 資料間で数字が異なった部分を、最終表でどちらに反映したか分かるか？

3つ目の項目が、実務で最も効果を発揮します。表の数字をすべて検証することはできません。代わりに「この数字が間違っていたら、レポートの結論が揺らぐか？」を基準に3つだけ選び、原文を直接開きます。検証にかける時間は、その3つに集中するのが適切です。

## 応用：派生数値はスプレッドシートに渡す

表に入る数字のうち、AIの計算に依存する割合が大きい場合は、計算そのものをAIに任せません。AIには原数字と出典だけを抜き出させ、成長率・合計はスプレッドシートの数式で作ります。

```
以下の資料から、表に入れる原数字だけを抜き出してください。計算はしないでください。

形式:
| 項目 | 数字 | 単位 | 基準時点 | 出典文 |

資料:
"""
[資料を貼り付け]
"""
```

返ってきた数字をスプレッドシートに移すと、成長率は数式で計算されます。AIに計算をまったくさせないため、算術ミスがなくなり、後で数字が変わっても数式だけを直せば済みます。原数字の入力が終わった後は、AIに「この表から、資料に根拠がなさそうな数字を選んでください」ともう一度尋ねるのも役立ちます。作成者が見つけられなかった欠陥を、別の視点で確認することになるからです。

## このプロンプトの限界

出典が付いているからといって、すべてが検証済みとは限りません。AIは出典をもっともらしく捏造します。「2024年事業報告書から引用」と書いてあっても、実際にはそのような文が存在しないことがあります。だからこそ出典の文まで照合できるようにしたのであり、最終確認は結局、人が原文を開いて行います。

Web検索なしでは最新の数字を使えないという限界も残ります。価格、市場規模、導入率などの外部数値で、AIの記憶にない時点の値が必要なら、検索できるツールを使うか、人が原出典を直接探す必要があります。検索結果を引用させる場合も、URLが実際に開くか、開いた文書にその数字が本当にあるかを確認する手順を省いてはいけません。

最後に、検証には判断が伴います。2つの資料が異なる場合、どちらを使うかは組織の基準に関わる問題です。最新の資料に従うのか、公式統計に従うのかは、AIが決めるのではなく、チームであらかじめ決めて表の注記に残しておく必要があります。表に数字を入れる人は、その数字への責任も一緒に入れるのだと考えてください。
