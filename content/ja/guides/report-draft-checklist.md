## 「レポート書いて」が作るもの

1ヶ月の売上レポートを書かなければならない。Excelファイルを開いてみるとデータはあるが、どこから始めればいいかわからない。AIに頼る。「今月の売上レポート書いて。」AIが3秒でレポートを返してくれる。段落ごとに番号があり、小見出しもあり、「結論」まである。読んでみる。それっぽい。

部長に送る。10分後に電話が来る。「前月比増減率がおかしいんだけど。数値合って？」もう一度データを確認する。AIが書いた増減率と実際のデータが違う。AIが数字を推定して埋めたのだ。また「B2Bチャンネルの成長傾向が顕著です」と書いてあるが、B2Bデータは全く見せたことがない。AIがそれっぽい文をでっち上げたのだ。

これが「レポート書いて」の結果だ。形式は完璧で内容は空っぽだ。

## 問題の原因

AIは**何を書くか**知ってこそちゃんと書く。「レポート書いて」は何を書くか教えてくれない。AIはこの状況で最もそれっぽいレポートの形式を作り出す。実際のデータを使うのではなく、「売上レポートにはこういう内容があるはずだ」と推定して埋める。

レポートが失敗するポイントは決まっている。構造がなく、データがなく、比較基準がなく、読者が誰かわかっていない。この4つのうち一つでも空けておくとAIが勝手に埋める。そしてその大部分が間違っている。

## 動くプロンプト

以下のプロンプトをレポート作成の出発点として使う。括弧内は実際の値に差し替える。

```
以下のデータを基に[レポートの種類]の下書きを作成してください。

条件:
1. レポートの目的: [このレポートで何を決定するのか]
2. 読者: [部長 / 役員 / クライアントなど]
3. 構造:
   - 概要（今回のレポートがなぜ必要か2文）
   - 主要数値（表で整理）
   - 前月/前四半期比の変化と原因
   - 特記事項（予想と違う点）
   - 次のステップの提案
4. 分析基準: [売上件数 / 売上額 / 純利益のうち何を基準にするか]
5. 比較期間: [2026年6月 vs 2026年5月]

データ:
"""
[ここにExcelからコピーしたデータを貼り付け]
"""

注意:
- データにない数値は絶対に作らないで
- わからないことは「データにありません」と書いて
- 推定が必要な部分は[推定必要]と表示して
```

## 7つのチェック項目

AIが返した下書きを送る前に必ず確認する。

**1. 数字は正確か？**
最もよく間違える部分だ。AIは数字を足したり引いたりするのにミスをする。下書きに出てくるすべての数値を元のデータと照合する。増減率、パーセンテージ、合計 — 一つずつ確認する。特に小数点の丸め方が違うケースが多い。

**2. データにない内容が入っているか？**
「B2Bチャンネルの成長傾向」のようにデータにない分析が入っていないか見る。AIはそれっぽい解釈を付け加える癖がある。データから直接確認できない内容は全部消す。

**3. 比較基準が明記されているか？**
「増加しました」 — 何に対して？前月比か、前年同月比か、目標比か。レポートで最もよく発生する誤解は比較基準が書かれていないことによるものだ。読者は自分なりの基準を仮定して読む。

**4. 因果関係の主張に根拠があるか？**
「新製品リリース効果で売上が増加しました」 — この因果関係をデータで証明できるか？AIはデータの相関関係を因果関係のように叙述する。因果を主張するなら根拠が必要で、なければ「同時期に新製品がリリースされた」程度にだけ書く。

**5. 読者が一度で読める分量か？**
レポートは誰かの意思決定ツールだ。10ページのレポートを読む人はいない。下書きが長すぎるなら概要と主要数値、次のステップだけ残して残りは付録に外す。読者が3分以内に結論に到達できなければならない。

**6. 「次のステップ」は実行可能か？**
「継続的なモニタリングが必要です」は次のステップではない。誰が、何を、いつまでにするのかが書かれていなければならない。AIが書いた次のステップが抽象的なら、具体的な行動に変える。

**7. 自分が説明できるか？**
下書きのすべての文について「なぜこう書いたのか？」という質問に答えられなければならない。答えられない文は信頼できない。AIが推定して書いた部分か、データにない解釈だ。見つけて消すか修正する。

## 応用：部門別レポートを一つにまとめる

チームメンバー各自がAIに部門レポートの下書きを作成させた後、一つにまとめなければならない時がある。この時各自のプロンプトを別々に書くとまとめるのが難しい。構造が違うからだ。

解決策はシンプルだ。チーム全体が同じプロンプト構造を使う。上のプロンプトをチーム共通テンプレートにし、各自のデータだけ変えて使う。そうすればまとめる時、構造が一致して一発でマージできる。

```
以下は部門別レポート3つです。同じ構造で作成されています。
これを一つの統合レポートにまとめてください。

条件:
- 各部門の主要数値を一つの表に統合して
- 共通して現れる特記事項は上部に要約して
- 各部門の次のステップは部門名を付けて別々に整理して
- 統合分析が必要な部分は[統合分析必要]と表示して

部門別レポート:
"""
[部門Aのレポート]
[部門Bのレポート]
[部門Cのレポート]
"""
```

## このプロンプトの限界

データの質が悪いと下書きも悪い。Excelでデータをコピーする時、列がずれたり、数字がテキストとして認識されたり、空白があったりするとAIが理解できない。データを貼り付ける前に最小限の整理 — ヘッダーの確認、空白の削除、単位の統一 — が必要だ。

また分量が多いデータを一度に入れるとAIが全体を処理できない。この場合はデータを部分に分けてそれぞれ分析させた後、結果をまとめる方式が必要だ。「長い文書をAIに読ませる方法」でこの方法を扱う。
