## 「競合分析して」が失敗する理由

企画会議や提案書の前に競合分析が必要になるとき、「A社・B社・C社を分析して」とAIに入力する。AIはもっともらしい比較表を返してきます。料金プラン、機能、市場での位置づけまで丁寧に整理されている。問題はその表を持って会議に入った瞬間に始まります。

AIが知っている料金は、学習時点の料金です。昨年発売の新製品は抜けており、終了したサービスは今も生きているように表示されます。さらに厄介なのは、存在しない項目です。AIは「競合分析」という課題を受けると、表の空欄をすべて埋めようとします。わからない項目は、同業他社にありそうな内容で埋めてしまう。一見完璧に見える表なので、数字を一つずつ確認するまで間違いだと気づけません。

競合分析が失敗するのは分析ではなく入力の段階です。最新情報をAIが持っていない以上、資料を探して集めるのは人がやり、AIにはその資料を構造化する役割だけを任せます。30分はこう分かれます。資料集め15分、プロンプトで構造化5分、検証10分。AIが全部やってくれる分析はありませんが、この進め方なら会議前に十分使える比較表ができます。

## 動くプロンプト

競合3社の料金ページ、プレスリリース、お知らせからテキストをコピーします。3社分なら15分で集まります。このときホームページの最初の画面にあるスローガンはコピーしません。マーケティング文句は比較表の材料になりません。料金、機能一覧、日付のついた発表など、確認できるものだけを集める。そして以下のプロンプトと一緒に送ります。

```
以下は競合3社のウェブサイトとプレスリリースからコピーしたテキストです。
この資料にある情報だけを使って比較表を作ってください。

比較軸（列は競合A/B/C）：
- 料金プラン：始まりの価格と内容
- 主要機能：資料に明記されているものだけ
- カスタマーサポート：チャネルと受付時間
- 最近の動き：日付のある項目だけ

条件：
- 資料にない項目は「資料になし」と表示してください。自分の知識で埋めないでください。
- 最近の動きの項目には日付を併記してください。
- 資料間で矛盾する内容があれば、表の下に別途まとめてください。

資料：
"""
[競合A 料金ページのテキスト]
[競合A お知らせの直近3件]
[競合B 料金ページのテキスト]
[競合B プレスリリース]
[競合C 製品ページの機能一覧]
"""
```

このプロンプトが「競合分析して」と違う点は3つあります。

第一に、**情報の出典をAIの記憶ではなく貼り付けた資料に限定した**ことです。AIは学習時点以降に変わった料金や発売情報を知りません。わからないことを尋ねる代わりに、確認済みの資料を渡してその範囲だけで作業させます。検索に使う15分がこのプロンプトの半分の価値です。

第二に、**比較軸を指定した**ことです。軸を渡さないとAIは各社のマーケティング文句から抜き出した表現で比較します。「革新的なプラットフォーム」と「オールインワンソリューション」を並べた表は、どの決断にも役立ちません。軸を自分で決めると、会議で実際に答えるべき質問と同じ形の表ができます。

第三に、**「資料になし」を許した**ことです。AIは空欄をそのまま放置しません。知らないと書くことを許可すると、でっち上げが目に見えるようになります。「資料になし」が多いということは、それ自体が情報です。追加で調べるべき項目という意味で、表の下の「要確認」リストに移します。

## 検証チェックリスト

AIが作った表をそのまま会議資料にしません。5分で確認します。チェックリストの順番どおりに進めるのが速いです。表の数字を元の資料と突き合わせ → 「資料になし」の位置を確認 → 軸が会議の質問と合っているか確認 → 日付を確認。この順番は、間違いを見つけられる確率が高いものから並べてあります。

- [ ] 表に入った価格と数値を元の資料と照合したか？
- [ ] 「資料になし」がそのまま残っているか？（AIが勝手に埋めていないか）
- [ ] 比較軸は会議で実際に聞かれる項目か？
- [ ] 最近の動きの項目すべてに日付がついているか？
- [ ] 自社製品を同じ軸で1行追加して比較したか？

最初の項目を飛ばすケースが一番多いです。表がきれいだと、確認なしで信じてしまいます。AIは資料を転記する過程で数字を統合したり丸めたりすることがあります。会議で数字が1つ違えば、表全体をその場で確認し直す事態になります。

## 応用：営業向けの1枚ガイドにする

比較表を社内報告で終わらせるのはもったいない。営業チームが現場で使える形に変えて展開します。

```
以下の比較表を営業チーム向けの1枚ガイドに変えてください。

含めるもの：
- 競合ごとの「我々が有利な点」を1行ずつ
- 顧客がよく聞く質問3つと回答文面
- 我々が不利な点と、そのときの回答の方向性

条件：
- 比較表にある事実だけを使ってください。根拠のないものは作らないでください。
- 文章は営業現場で話すように書いてください。

比較表：
"""
[先ほど作った比較表を貼り付け]
"""
```

この応用は事実の整理ではなく、自社製品の立場からフレームを作る作業です。「有利な点」を誇張すると、現場で信頼を失います。展開前に営業チームのレビューを通します。現場から入ってきた顧客の反応を比較表の「最近の動き」に追加し続けると、四半期ごとにガイドが更新されます。

## このプロンプトの限界

資料を集めるのは人の仕事です。どの資料を見るか判断するのも人の役割です。競合の非公開情報 — 売上、顧客数、契約条件 — はどんなプロンプトでも出てきません。この数字が必要なら、有価証券報告書や業界レポートを別途確認します。AIが「推定値」を出してきたら、そのまま使わず捨てます。推定値は根拠が公開されていなければ、反論する方法もありません。

競合のウェブサイトがマーケティング文書である点も限界です。「業界最多」、「10万人が選んだ」のような文句は検証されていない主張のことが多いのに、AIはこれを事実のように表へ転記します。確認できる数値（公開価格、日付のある発表）と確認できない主張を区別するのは、結局人の目の仕事です。この作業をAIに任せてはいけません。AIには文句の真偽を判断する根拠がありません。

最後に、比較表はある時点のスナップショットです。料金プランは四半期ごとに変わります。表に作成日を書いておき、3ヶ月経ったら作り直します。古い表を持ったまま顧客に会うのが、競合分析で最もよくある事故です。
