## 「この会議、何の会議？」を会議室で聞く瞬間

招待状には「Q4プロモーションの運用状況および改善策の議論」としか書いていない。この会議が何のためのものか知っているのは主催者だけで、自分は前四半期の資料を探しながら会議室に入る。最初の20分は、自分が読んでいなかった資料の説明を聞くことに消える。ようやく質問をひとつ投げると、「その件は前回の会議で持ち上がりましたよ」と返ってくる。参加者10人がそれぞれ20分を失えば、3時間が消える。会議のコストは実際こうして積み上がる。

会議の準備ができない理由は、たいてい時間がないことではない。どこから読めばいいかわからないこと、そして読んだとしても何を押さえるべきか整理できていないことだ。報告書3本に目を通すには40分かかるが、40分の余裕がある日はほとんどない。だから準備は後回しになり、後回しにされた準備は会議室の中で露見する。

AIはこの隙間に入れる。資料の要約役ではなく、**自分がこの会議で何を押さえるべきかを先に整理してくれる役**だ。ただし「この資料を要約して」でも失敗する。会議前に必要なものは要約ではないからだ。会議前に必要なのは要約ではなく、質問だ。

## 動くプロンプト

下のプロンプトをコピーして、括弧の部分を状況に合わせて書き換え、背景資料を最後に貼り付ける。

```
下の資料をもとに、会議前のブリーフィングを作ってください。

会議情報：
- テーマ：［例：Q4プロモーションの運用状況と改善策］
- 主催者：［例：マーケティングチームのリーダー］
- 自分の立場：［例：IT Planning担当。予算・システム要件のレビュー］
- この会議で持ち帰るべきもの：［例：システム変更要件の規模と優先順位］

ブリーフィングの形式：
1. 会議の背景（この議題がなぜ今話されているのか、3文以内で）
2. これまでの経緯（前回の会議や資料で決まったこと、保留になったこと）
3. 重要な数字・日程（資料に載っている数値と期限だけを拾って）
4. 自分に関係する論点（自分の立場で押さえるべき部分だけ）
5. 会議で聞くべき質問の候補3〜5個（答えが得られれば自分の判断に役立つもの）

資料：
"""
［会議の招待状、前回の議事録、参考レポートなどを貼り付け］
"""
```

このプロンプトが資料要約と違う点は3つある。

第一に、**自分の立場を伝えている**。同じ資料でも、マーケティング担当にとって重要な部分と、IT Planning担当にとって重要な部分は違う。立場を指定しないと、AIは誰にでも等しく重要そうに見える中立的な要約を作り、その要約は自分には役に立たない。

第二に、**持ち帰るべきものを先に定義している**。「予算・システム要件のレビュー」という目的があるので、資料の中でもその部分だけが吟味される。会議前30分の目的は資料を全部知ることではなく、自分が判断できる最少限を整えることだ。

第三に、**質問候補を出させている**。ここがこのプロンプトの芯だ。準備できている人とできていない人の差は発言量ではなく、質問の精度だ。候補を受け取って磨いて持っていけば、会議での自分は「前回の決定を知らない人」ではなく「論点を突く人」になる。

## 検証チェックリスト

AIが作ったブリーフィングを信じたまま会議室に入らない。2分だけ確認する。

- [ ] 重要な数字・日程は資料に実際にある値か？（AIがもっともらしい数字を作り出すことがある）
- [ ] 「これまでの経緯」の「決まったこと」は本当に決まったことか？（話し合っただけのものを決定に移すと、会議が絡まる）
- [ ] 質問候補のうち、自分の立場に合わないものを外したか？
- [ ] 自分がすでに知っている内容と違う部分はないか？（あれば、資料が最新ではない可能性がある）

最初の項目がいちばん危険だ。ブリーフィングは会議の途中で広げて見る文書なので、間違った数字をそのまま引用しやすい。会議室で誤った数値を根拠に発言すると、その数字を訂正するために残りの時間を使うことになる。

## 応用：1週間分をまとめて処理する

週に定例会議が4つある人は、毎回この作業をする余裕はない。金曜日に1週間分をまとめて回す。

```
下は来週出席する4つの会議の招待状と背景資料です。
会議ごとに、上と同じ形式のブリーフィングを作ってください。

追加の条件：
- 同じ議題が複数の会議で扱われる場合、その議題の決定がどの会議で出るかを示してください
- 自分が準備していくべき資料や数字があれば、会議ごとに分けてください
- 複数の会議にまたがる論点があれば「今週の貫通イシュー」として別にまとめてください

資料：
"""
［会議ごとに招待状と資料を区切って貼り付け］
"""
```

1週間を見下ろすと、個別の会議だけ見ているときには見えないものが見える。火曜日の会議で決まる事項が木曜日の会議の前提になっている場合、火曜日を適当に過ごせば木曜日に流される。「貫通イシュー」としてまとめるよう頼むのはそのためだ。

## このプロンプトの限界

背景資料がなければブリーフィングもない。招待状が1行だけで前回の議事録も手に入らない状態でこのプロンプトを回すと、AIは存在しない背景を作り出す。そのとき作られた「これまでの経緯」はすべて推測であり、推測を持って会議室に入るのは、準備しないで入るより危険だ。資料が2件以下なら、ブリーフィングの代わりに主催者に直接聞く方が早い。

組織の政治地形はこのプロンプトの外にある。どの質問が主催者を刺激するか、前回の会議で誰が引いたかは、資料には書かれていない。AIが挙げた質問候補を全部口にする人より、その中から状況に合う2〜3個だけを選ぶ人の方が会議がうまい。質問を選ぶ基準は、依然として人が持っていなければならない。
