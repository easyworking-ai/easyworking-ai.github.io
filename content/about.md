# 사이트 소개

## 일하는 AI란

일하는 AI는 AI를 실제 업무에 붙일 때 생기는 판단 문제를 다루는 콘텐츠 사이트입니다.

회의록을 정리하고, 이메일을 쓰고, 엑셀을 분석하고, 에이전트를 도입하는 과정에서 AI가 무엇을 잘하고 어디서 틀리는지 실무 장면을 기준으로 설명합니다.

## 다루는 콘텐츠

- **가이드**: 회의록·이메일·엑셀처럼 반복되는 업무에 적용하는 프롬프트와 검수 방법
- **학습**: 챗봇, 에이전트, RAG, 컨텍스트 윈도우 등 업무에 필요한 개념
- **라디오**: 한 주의 AI 뉴스를 고르고, 실제 업무와 연결해 설명하는 오디오 콘텐츠
- **체험**: AI의 답을 비교하고 직접 판단해 보는 인터랙티브 도구
- **실습노트**: 도구를 설치하고 사용한 과정에서 확인된 것과 아직 확인하지 못한 것을 구분한 기록

## 편집 기준

사이트의 글은 다음 원칙을 따릅니다.

1. 도구 이름보다 실제 업무 장면을 먼저 설명합니다.
2. AI가 낸 결과를 그대로 믿지 않고 검수 지점을 함께 제시합니다.
3. 현재 정보나 수치가 필요한 글에는 가능한 한 원문 출처와 확인 시점을 표시합니다.
4. 직접 실행한 내용, 계획 중인 내용, 아직 확인하지 못한 내용을 구분합니다.
5. 오류가 확인되면 글을 수정하고 필요한 경우 정정 내용을 표시합니다.
