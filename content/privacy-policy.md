# 개인정보처리방침

시행일: 2026년 8월 23일

일하는 AI(EasyWorking-AI, 이하 “사이트”)는 방문자의 개인정보와 이용 기록을 필요한 범위에서만 처리합니다. 이 문서는 사이트의 공개 페이지와 체험 도구를 이용할 때 어떤 정보가 처리될 수 있는지 설명합니다.

## 1. 처리하는 정보

사이트는 회원가입을 요구하지 않습니다. 다음 정보가 기능 이용 과정에서 처리될 수 있습니다.

- 페이지를 요청할 때 서버와 브라우저가 전달하는 접속 시간, 요청 주소, 브라우저·기기 정보, IP 주소 등 기술 정보
- GoatCounter 분석 도구를 통한 페이지 조회와 방문 흐름 정보
- 사용자가 직접 출간 알림이나 AI 업무 진단 결과 저장을 신청할 때 입력하는 이메일 주소와 선택적 이름·직군
- 언어와 테마 선택을 유지하기 위해 브라우저의 `localStorage`에 저장되는 설정값
- 문의 메일을 보낼 때 사용자가 메일 본문에 직접 적은 내용

## 2. 이용 목적

처리되는 정보는 다음 목적으로만 사용합니다.

- 사이트와 콘텐츠의 오류 확인 및 보안 유지
- 어떤 글과 체험 도구가 실제로 이용되는지 파악하고 콘텐츠를 개선
- 사용자가 요청한 출간 알림 또는 진단 결과 안내
- 문의에 답변하고 정정·저작권 요청을 처리

## 3. 체험 도구와 이메일

AI 업무 진단 도구에서 이메일을 입력하는 것은 선택 사항입니다. 사용자가 결과 저장을 신청하면 이메일과 선택 입력값, 진단 결과가 외부 webhook으로 전송될 수 있습니다. 전송이 실패하면 메일 앱을 통한 `mailto:` 방식이 사용될 수 있습니다.

이메일을 입력하지 않아도 진단 결과를 확인할 수 있는 경로를 제공합니다. 알림 수신을 중단하거나 자신의 정보를 삭제해 달라고 요청하려면 아래 문의 주소로 요청해 주세요.

## 4. 분석 도구와 외부 서비스

사이트의 글꼴, 수식 표시, 체험 도구와 연결된 외부 서비스가 브라우저 요청을 받을 수 있습니다. 외부 사이트로 이동하거나 외부 서비스에 정보를 제출할 때는 해당 서비스의 개인정보처리방침도 확인해야 합니다.
