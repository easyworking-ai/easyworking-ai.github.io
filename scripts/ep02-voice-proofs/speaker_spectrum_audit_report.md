## 4. 판정 요약

### 핵심 발견

**EP04 '탁함'은 화자 고유 문제가 아닌 에피소드 전반 문제다.**

1. **EP04 전체 파일 presence 밴드(2-5kHz) 붕괴**: -38.1 dB (EP02: -32.8 dB, EP03: -32.1 dB). EP02 대비 **-5.3 dB** 하락. 이는 iro/loop 모두 동일하게 -37.7/-37.6 dB로 나타나 **화자 간 차이 없음** (loop - iro = +0.1 dB).

2. **EP03은 고역/에어가 오히려 살아있음**: EP02 대비 6-8kHz에서 +6~10 dB, 8-12kHz에서 +9~13 dB 상승. EP03은 고역 EQ가 EP02와 다르게 적용되었거나 마스터링이 다름.

3. **화자별 차이는 EP03에서만 나타남**:
   - EP03에서 loop의 6-8kHz: -37.2 dB, iro의 6-8kHz: -33.7 dB → **loop가 3.5 dB 더 낮음 (탁함)**
   - EP03에서 loop의 8-12kHz: -37.8 dB, iro의 8-12kHz: -34.3 dB → **loop가 3.5 dB 더 낮음**
   - EP02와 EP04에서는 iro/loop 차이가 ±1 dB 이내로 무의미함.

4. **EP02 라인 승인본 vs MP3 비교**: v8_iro 라인은 overall -9.5 dB로 매우 크지만, MP3 내 iro 세그먼트는 -15.7 dB. MP3 믹싱/마스터링 과정에서 약 6 dB 감쇄됨. 라인의 presence(-30.8 dB)와 MP3의 presence(-32.6 dB) 차이는 1.8 dB로 양호함.

5. **proof_A (현재 EP04 상태) vs proof_D (iro 재생성)**: presence에서 -36.6 dB vs -30.9 dB → **재생성이 5.7 dB 더 밝음**. 이는 EP04 MP3의 presence 손실이 라인 생성 자체의 문제가 아니라 **최종 믹싱/마스터링의 EQ 처리**에서 기인할 가능성이 높음.

### 최종 판정

| 판정 항목 | 결과 |
|-----------|------|
| 루프 탁함이 EP04에서 화자 고유 문제인가? | **아니오** — iro/loop 거의 동일한 수준 |
| EP04 탁함의 원인은? | **에피소드 전반의 presence(2-5kHz) 대역 붕괴** |
| EP03에서 loop만 탁한가? | **예** — EP03에서만 loop가 고역에서 3.5 dB 낮음 |
| EP04 MP3 presence 손실 원인? | **라인 생성보다 믹스/마스터 EQ의 영향이 큼** (proof_A vs proof_D 비교) |
| 개선 권고 | EP04 전체에 2-5kHz 부스트 EQ (+3~5 dB), MP3 마스터링 단계에서 highpass cutoff 재확인 |
